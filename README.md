# T11 장편소설 작업 방식 기록

이 저장소에는 소설 원고가 없습니다. 원고는 개인적인 이야기라 공개하지 않고, 과제 안내에 따라 파일 한 개로만 제출했습니다. 여기에는 소설을 **어떻게 만들었는지**만 적습니다.

## 작업 방식

1. **질문 70개에 직접 답했다.** 소설에 넣을 사실을 AI에게 질문해 달라고 요청했고, AI가 만든 70개 질문에 내가 직접 대답했다.
2. **리추얼 기록을 적극 활용했다.** 교육 과정에서 매일 남긴 리추얼 기록(날짜별 일화와 동료가 해 준 말)을 소설의 사건과 대사에 적극 활용했다.
3. **AI가 초안을 썼다.** 내 대답과 리추얼 기록을 바탕으로 AI가 장별 초안과 대조표(인물·관계·지명·시간선·세계 규칙), 장별 인과표를 가져왔다.
4. **편집기를 만들어 직접 수정했다.** 초안을 읽어 보니 사실과 다른 문장이 많아서, 내가 직접 고칠 수 있는 편집기 웹사이트를 요청해 만들었다. 이 편집기에서 전체를 처음부터 끝까지 읽어 가며 필요한 부분을 직접 검토하고 수정했다. 모든 장에 내 손이 닿았다.
5. **다시 만들고 검사했다.** 편집기의 버튼 하나로 제출용 원고 파일을 다시 조립하고, 과제 기준을 하나씩 확인하는 검사 도구를 돌렸다(분량, 목차와 본문 일치, 중복 문단, 금지 문구, 대조표 연결 등).

## 편집기

컴퓨터 안에서만 도는 웹 창이고, 장을 고른 뒤 문단을 직접 고치면 바로 파일에 저장된다. 인터넷에 올리지 않는다.

### 창을 나가면 어떻게 되나, 어디에 저장되나

창을 닫거나 다른 페이지로 나가도 고친 내용은 사라지지 않는다. 편집기는 문단을 고치면(입력을 멈추고 약 1초 뒤, 또는 다른 칸으로 옮길 때) 바로 컴퓨터의 장별 파일에 저장한다. 브라우저 안의 임시 저장이 아니라 작업 폴더의 파일이라서, 편집기를 다시 열거나 새로고침하면 이 파일에서 내용을 다시 불러와 저장된 그대로 보인다. 저장이 끝나기 전에 창을 닫으려 하면 경고가 뜬다. 브라우저에는 마지막으로 보던 장 번호만 기억해 둔다.

### 저장이 작동하는 방식

데이터베이스나 예약 작업(스케줄러)을 쓰지 않는다. 브라우저 코드가 입력이 멈춘 뒤 내 컴퓨터의 작은 서버에 보내고, 서버가 파일에 쓴다.

1. 문단에 글자를 입력하면 입력 이벤트가 발생하고, 브라우저가 0.8초 타이머를 건다. 그 안에 다시 입력하면 타이머를 취소하고 다시 건다(디바운스).
2. 입력이 0.8초 동안 멈추거나, 칸에서 커서를 빼면 바로 저장 요청을 서버로 보낸다. 서버는 내 컴퓨터 안에서만 접속된다.
3. 서버는 해당 문단만 바꿔서 장별 파일에 쓴다. 쓰기 전에 직전 판을 백업 폴더로 복사한다(같은 분 안에서는 한 번만).
4. 파일은 임시 파일에 먼저 쓴 뒤 교체한다. 쓰는 도중 꺼져도 반쯤 쓰인 파일이 남지 않는다.
5. 주기적으로 도는 작업은 없고, 입력이 있을 때만 저장한다. 즉 "1초마다"가 아니라 "입력을 멈추고 약 1초 뒤"에 저장한다.
6. git 커밋은 자동으로 하지 않는다. 다시 만들기 버튼을 누를 때만 커밋하고, 푸시는 내가 직접 요청할 때만 한다.

서버가 꺼져 있으면 저장되지 않고 화면에 안내가 뜬다.

### 백업하는 방법

내용이 사라지지 않도록 여러 겹으로 저장했다.

1. **저장 즉시 파일에 쓴다.** 문단을 고치면 약 1초 뒤 장별 파일에 바로 저장된다. 브라우저에만 저장하지 않으므로 창을 닫거나 프로그램이 꺼져도 고친 내용은 남는다.
2. **저장할 때마다 이전 판을 백업한다.** 1분 단위로 직전 판이 시각이 붙은 파일로 쌓인다.
3. **git 커밋.** 편집기의 다시 만들기 버튼을 누르면 변경 내용이 로컬 git에 커밋되어 이전 상태로 되돌릴 수 있다.
4. **비공개 저장소에 백업.** 집에서도 작업하려고 비공개 저장소에 올렸다. 개인 이야기가 담겨 있으므로 공개하지 않는다.
5. **작업본 압축 파일.** 원고와 도구를 한 파일로 묶어 USB나 개인 드라이브로 옮길 수 있게 했다.

덮어쓰기 방지 장치도 있다. 편집기는 문단을 저장할 때 그 문단의 원래 내용을 함께 보내고, 파일의 내용이 다르면 저장을 거부하고 새로고침을 안내한다. 그래서 오래 열어 둔 화면이 최신 수정을 덮어쓰지 못한다.

### 되돌리는 방법
1. 백업 폴더에서 되돌리고 싶은 시각의 파일을 찾는다.
2. 그 내용을 해당 장 파일에 덮어쓴다.
3. 편집기 화면을 새로고침한다.
